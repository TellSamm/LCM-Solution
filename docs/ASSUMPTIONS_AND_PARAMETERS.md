# Допущения, ограничения и конфигурируемые параметры

## 1. Допущения

| № | Допущение | Обоснование / риск |
|---|---|---|
| A1 | Трамвай движется по известному маршруту Щукинская ↔ Таллинская (pathgraph организаторов + разворотные петли на конечных). Положение публикуется как точка карты на пройденной дуге. | Эксперт на Q&A: «маршрут един в бэгах и на проверке». Заезды в депо и на другие ветки картой не покрыты - там положение будет «сползать» по карте (см. ограничения). |
| A2 | Трамвай едет только вперёд вдоль своего направления; датчики колёс дают модуль скорости. | Односторонний вагон «Львёнок», разворот через петли; в данных отрицательных скоростей нет. |
| A3 | Датчики скорости колёс - в **км/ч** (README ошибочно указывает м/с). | Подтверждено регрессией к GNSS (коэффициент 3.60) и словами эксперта. |
| A4 | Масштаб одометрии (эффективный радиус колеса) постоянен в течение прогона и равен калибровочному значению для данного трамвая. | Между датами записей масштаб меняется до ~1 % (износ/обточка). Без GNSS онлайн не наблюдаем -> дрейф до ~1 % дистанции в худшем случае. |
| A5 | Тяговая характеристика трамвая описывается таблицей удельного ускорения $a(n,v)$, идентифицированной по обучающим прогонам; масса пассажиров и потери привода входят в неё усреднённо. | Модель нужна как страховка при аномалиях одометрии (доли процента времени) - её точности ±0.1 м/с² достаточно. |
| A6 | GNSS доступен в первые секунды прогона (трамвай стоит на разворотном кольце конечной); в рабочем режиме GNSS не используется. | Подтверждено организаторами (ответ в чате капитанов): GNSS на старте гарантируется, старт/финиш - разворотные кольца Щукинской и Таллинской. Если GNSS всё же нет - старт из `default_start`. |
| A7 | Эталонная позиция - base_link (ось вращения передней тележки); антенны master/rover на продольной оси на $x=-9.873$ и $+2.563$ м. | Данные из чата капитанов. |
| A8 | По умолчанию - калибровка трамвая 30618 (организаторы: проверка только на нём). Калибровка 30639 и усреднённая переключаются параметром `tram_id`. | Разница калибровок: масштаб 0.4 %, тяга при высоких позициях до 15 %. |
| A9 | Высота $z$ берётся из карты (профиль pathgraph). | Эксперт: Z «необязательно, все в одинаковых условиях». |

## 2. Ограничения решения

1. **Вне карты** (депо, служебные ветки, другой маршрут) положение проецируется на ближайшую по дуге точку кольца -
   ошибка растёт до ухода с ветки. В обучающих данных таких прогонов ~5 %.
2. **Стартовая точка вне карты**: если трамвай стоит на платформе, которой нет в карте (у Таллинской несколько параллельных путей),
   начальная привязка даёт смещение по дуге, которое сохраняется весь прогон (в данных: 25 % прогонов стартуют >10 м от карты ->
   медианная ошибка положения таких прогонов 20–50 м против 8–12 м у остальных).
3. **Масштаб колёс** не адаптируется онлайн (нет наблюдения без GNSS) -> систематический дрейф 0.1–1 % дистанции.
4. **Одновременное зависание обоих датчиков** обнаруживается только если модель предсказывает изменение скорости
   (>0.3 м/с за 4 отсчёта); при равномерном движении зависание неотличимо от нормы (и безвредно).
5. **Пропуск всех входов** (колёса и контроллер) дольше 10 с -> состояние замораживается (без фантомного движения);
   до 1 с - интегрируется модель, 1–5 с - публикуется последнее состояние с флагом `status=3`.
6. Направление движения на старте при одной антенне определяется по ближайшей точке карты: на участке двух параллельных
   путей (3.5 м) возможна ошибка выбора направления при GNSS-ошибке >1.7 м. С двумя антеннами направление
   определяется по их взаимному положению и однозначно.
7. Позиция контроллера $-8$ у обоих трамваев даёт аномально слабое замедление в данных - модель воспроизводит измеренное;
   физическая причина не известна.

## 3. Конфигурируемые параметры (`config/params.yaml`, `ros2 launch ... tram_id:=... default_start:=...`)

### Идентификация и старт
| Параметр | По умолчанию | Смысл |
|---|---|---|
| `tram_id` | `30618` | `30618` (линейный, проверка жюри) / `30639` (лаборатория) - выбор калибровки (масштабы колёс, таблица тяги). Пусто -> `calib_default` (усреднённая). |
| `calib` | `auto` | Явный выбор файла калибровки: `auto` / `30618` / `30639` / `default`. |
| `default_start` | `stop_S` | Стартовая точка без GNSS: `stop_S` (конечная Щукинская), `stop_T` (Таллинская), `A_start`, `B_start` или число - метры вдоль кольца. |
| `gnss_init_seconds` | 5.0 | Окно после первого входа, в котором GNSS используется для выставки; после окна GNSS принимается только пока трамвай ещё не тронулся (стоит на конечной); после начала движения - игнорируется всегда. |
| `init_wait` | 3.0 | Ожидание GNSS (с) до перехода на `default_start`. |
| `init_min_fixes` | 5 | Минимум фиксов для выставки (усреднение). |
| `map_file` | `assets/track_ring.json` | Карта: x, y, z, курс, кривизна, уклон с шагом 1 м, маркеры конечных. |

### Калибровка трамвая (`assets/calib_<id>.yaml`)
| Поле | 30618 | 30639 | Смысл |
|---|---|---|---|
| `wheel_scale_front` / `rear` | 1.00134 / 1.00131 | 0.99693 / 1.00044 | масштаб одометрии (эфф. радиус колеса) |
| `kmh_to_ms` | 1/3.6 | 1/3.6 | единицы датчиков |
| `accel_table[31×16]` | - | - | удельное ускорение $a(n,v)$, м/с², позиции −15..15 × скорость 0.5..15.5 м/с |
| `k_curve` | 3.0 | 3.0 | сопротивление в кривых, м²/с² (0.1 м/с² при R = 30 м) |
| уклон | из карты | из карты | $-g\,i(s)$, сглаживание 30 м |

Физические константы, которые **не** нужны как отдельные параметры (входят в удельное ускорение): масса
(27.5 т пустой), радиус колеса, передаточное число, коэффициенты сопротивления. Они могут быть введены явно при
переходе к силовой модели (см. план развития).

### Фильтр и отбраковка
| Параметр | По умолчанию | Смысл |
|---|---|---|
| `q_accel` | 1.0 м/с² | процессный шум (неопределённость модельного ускорения) |
| `r_wheel` | 0.10 м/с | шум измерения скорости колёс |
| `gate_sigma` | 4.0 | ворота по невязке, σ |
| `gate_min` | 0.5 м/с | минимальные ворота (порог проскальзывания/юза) |
| `stuck_repeats` | 4 | повторов одинакового значения для признака зависания |
| `stuck_min_pred_change` | 0.3 м/с | модельное изменение скорости за окно повторов |
| `stuck_min_speed` | 0.3 м/с | ниже - нули считаются стоянкой |
| `reject_timeout` | 4.0 с | принудительный перезахват одометрии |
| `adapt_r` | false | адаптивный шум измерений по медиане невязок |
| `max_gap` | 10 с | максимальный пропуск входов, перекрываемый моделью |
| `scale_sigma` | 0.003 | отн. неопределённость масштаба -> ковариация положения |
